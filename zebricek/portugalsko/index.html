O co hraje — místa v pohárech 2028/29

Při současném 6. místě: LM: 2 přímo + 1 kval. · EL: 1 přímo + 1 kval. · KL: 1 kval.

  • LM — Mistr → ligová fáze
  • LM — 2. místo → ligová fáze
  • LM — 3. místo → 3. předkolo (ligová větev)
  • EL — Vítěz poháru → ligová fáze
  • EL — 4. místo → 2. předkolo
  • KL — 5. místo → 2. předkolo

Podle základní přístupové listiny UEFA; o místech rozhodne až konečné pořadí okna. Jednorázové posuny volných míst se nepočítají.
